# Portafolio Básico

Proyectos pequeños y autocontenidos. Cada carpeta numerada es un proyecto independiente, con su propia tecnología, su README y su licencia.

| # | Proyecto | Tecnología | Descripción |
|---|----------|------------|-------------|
| 01 | [Bin2Dec](01-bin2dec/) | Python, GTK4, Flatpak | Conversor binario ↔ decimal en tiempo real |
| 02 | [Border Radius Previewer](02-border-radius-previewer/) | HTML, CSS, JS | Previsualizador de `border-radius` con CSS copiable |

## Cómo está organizado

- Cada proyecto vive en su carpeta numerada (`NN-nombre`).
- Cada proyecto es autocontenido: no comparte código ni dependencias con los demás.
- Cada proyecto tiene su propio `README` con instrucciones de construcción y uso.
